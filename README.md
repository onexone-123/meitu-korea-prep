# Seoul Notes

美图韩国市场运营研究与原创模拟提案集。独立展示项目，非美图官方网站。

## 网站内容

市场与产品、运营方法与交付、韩语内容实验室、KOL 合作计算器、本地化研究与韩国热点日报。

- 公开事实附来源，集团数据与韩国数据区分。
- 活动、合作方案及演示投放数据均为模拟材料，尚未执行。
- 网站不收集访客信息；可下载项目摘要。
- 静态网站，无后端、账号或秘密密钥。

## 运行与发布

网站文件在仓库根目录：`index.html`、`style.css`、`app.js`、`hotspots.json`。
GitHub Pages 使用 `main` 分支根目录发布。可用任意静态 HTTP 服务本地预览。

## 热点更新约定

每日更新由当前 Codex 对话中的定时任务执行，默认北京时间 09:00。需要 Codex 定时任务正常运行、网络及 GitHub 连接可用。

更新 `hotspots.json`，保留结构：

- `updatedAt`：实际核验时间，ISO 8601，含时区；不得虚写。
- `window`：选题时间窗口。
- `dataBoundary`：数据边界，避免把选题线索包装成全网热搜。
- `items`：3–5 条优先近 24–72 小时的消息；不足时扩展至 7 日，仍不足则少收录。
- 每条包含 `id,title,category,publishedDate,eventDate,summary,angle,sourceName,url,confidence,dataBoundary`。
- `summary` 只写核实的事实；`angle` 是独立的原创运营提案。
- 明确来源发布日期与事件日期，过去活动不得标为即将发生。
- 官方来源优先；缺乏可靠消息时如实说明，不编造热度、销量或排名。
- 更新后校验 JSON、来源与 Pages 发布状态。不添加个人履历、联系方式或未授权数据。
